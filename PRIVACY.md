# Privacy Policy — Invoice Tenken (free edition)

Last updated: 2026-11-22

## English

**What this plugin does with data.** The tools of this plugin run on your own computer. They receive only the values Claude passes to them (for example the issuer name, registration number, dates and amounts read from an invoice) and return the result of the checks. They do not open network connections, do not send data to the developer or to anyone else, and do not store, log or keep any data after a check.

**Claude itself.** Claude reads your documents and conversation as part of the Claude service. That processing is governed by Anthropic's terms and privacy policy, not by this plugin.

**No collection.** The developer does not collect analytics, telemetry, personal data or conversation content.

**Contact.** Questions about this policy: open an issue in this plugin's GitHub repository.

## 日本語

**このプラグインのデータの扱い.** このプラグインの道具は、お使いのパソコンの中だけで動きます。受け取るのは Claude が渡す値（請求書から読み取った発行者名・登録番号・日付・金額など）だけで、点検の結果を返します。通信はせず、作者やほかの誰にもデータを送らず、点検の後にデータを保存・記録しません。

**Claude 本体.** 書類や会話は、Claude のサービスとして Claude が読みます。その扱いは Anthropic 社の規約とプライバシーポリシーによります（このプラグインの扱いではありません）。

**集めないもの.** 作者は、利用状況の計測・個人情報・会話の内容を集めません。

**問い合わせ.** このポリシーについては、このプラグインの GitHub リポジトリの Issue でお尋ねください。
