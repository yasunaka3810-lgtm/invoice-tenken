# インボイス点検（Invoice Tenken）— Claude で請求書・領収書を点検するスキル

[English](README.md)

請求書や領収書の PDF・写真を Claude に渡して「インボイスの要件で点検して」と頼むと、Claude が書いてあるとおりに読み取り（書いていない値は推測しません）、次の順に点検します。

- **記載事項**: 適格請求書・簡易インボイス（レシート）・返還インボイス（消費税法 第57条の4）。8%の品目の「軽減税率の対象である旨」の書き方も（インボイスＱ＆Ａ 問73）。
- **登録番号**: 「T＋13桁」の形と、法人番号の検査用数字。
- **税率ごと（10%・8%）の消費税額**: どの端数処理で合うか、明細ごとの端数処理の合計になっていないか、消費税の合計と請求金額（施行令 第70条の10）。
- **電子帳簿保存法のファイル名**（一問一答 問50）。

どの指摘も「エラー・注意・情報」に分け、根拠（条・ページ・URL）を付けます。根拠は消費税法・施行令（e-Gov）と国税庁の資料だけです（[skills/invoice-tenken/references/rules.ja.md](skills/invoice-tenken/references/rules.ja.md)）。

> これは確認の補助です。税務の判断は、ご自身か税理士にお願いします。

## 点検のしかた

このプラグインに入っているのはスキル（手順と表）だけで、プログラムは入っておらず、どこにも何も送りません。Claude は [manual-check.md](skills/invoice-tenken/references/manual-check.md) の手順を一つずつ確かめ、計算はコード実行が使えればコードで行います。

同じ点検をプログラムで行う無料の道具（パソコンで動く MCP サーバー）は、このリポジトリの `main` の枝で配っています: https://github.com/yasunaka3810-lgtm/invoice-tenken 。道具があるときは、スキルが道具を使います。
