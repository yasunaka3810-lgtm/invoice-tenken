# インボイス点検（Invoice Tenken）— Claude で請求書・領収書を点検

[English](README.md)

受け取った請求書や領収書の PDF・写真を Claude に渡して「インボイスの要件で点検して」と頼むと、記載事項・登録番号の形・税率ごとの消費税と端数処理を点検し、電子帳簿保存法に合うファイル名も提案します。どの指摘にも、根拠の条文や国税庁の資料（ページ・URL）が付きます。

> これは確認の補助です。税務の判断は、ご自身か税理士にお願いします。

## 点検すること

| 道具 | 内容 |
|---|---|
| `check_invoice_fields` | 適格請求書・簡易インボイス（レシート）・返還インボイスの記載事項（消費税法 第57条の4） |
| `check_tax` | 税率ごと（10%・8%）の消費税額、どの端数処理で合うか、明細ごとの端数処理の合計になっていないか、合計金額（施行令 第70条の10） |
| `check_registration_number` | 登録番号の形（T＋13桁）と、法人番号の検査用数字 |
| `suggest_filename` | 日付・取引先・金額を決まった順に入れたファイル名の案（電子帳簿保存法一問一答 問50） |
| `list_sources` | 根拠の資料の一覧 |

スキル `invoice-tenken` が、書類を読む → 書いてあるとおりに取り出す（書いていない値は推測しない）→ 道具で点検する → 根拠つきで報告する、という手順を Claude に教えます。

## 根拠

消費税法・施行令（e-Gov）と国税庁の資料（適格請求書等保存方式の概要・インボイスＱ＆Ａ・電子帳簿保存法一問一答・法人番号の構成）だけです。一覧は [skills/invoice-tenken/references/rules.ja.md](skills/invoice-tenken/references/rules.ja.md)。

## 使える場所

- **Claude Code** と **Cowork**（自分のパソコンで動くとき）: スキルと道具の両方。
- **Claude のチャット**: スキルは読み込まれますが、パソコンで動く道具はチャットでは起動しません。そのときは Claude が同じ決まりで手で点検し、報告にそう書きます。

道具は Node.js で、パソコンの中だけで動きます。このプラグインは通信をしません。[PRIVACY.md](PRIVACY.md) を見てください。
