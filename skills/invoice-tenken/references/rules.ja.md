# 点検の決まりと出典（日本語）

すべて公式の資料だけを根拠にしています。資料の版を変えたら、この表と `server/src/lib/sources.ts` を一緒に直します。

| 点検すること | 決まり | 出典 |
|---|---|---|
| 適格請求書の記載事項 | ①発行者の氏名又は名称と登録番号 ②取引年月日（まとめて作る場合は期間） ③取引の内容（軽減税率の対象なら、その旨） ④税率ごとに区分して合計した対価の額（税抜又は税込）と適用税率 ⑤税率ごとに区分した消費税額等 ⑥交付を受ける事業者の氏名又は名称 | 消費税法 第57条の4第1項／国税庁「適格請求書等保存方式の概要」（令和8年4月）P4 |
| 軽減税率の対象である旨の書き方 | 客観的に明らかであればよい。明細ごとに適用税率を書く、印（＊・※など）を付けてその意味を書く、軽減税率の対象を区分して書きその旨を示す、別の請求書に分けてその旨を示す、のどれでもよい | 国税庁「適格請求書等保存方式に関するＱ＆Ａ」（令和8年5月改訂）問73 |
| 簡易インボイスの記載事項 | ①〜④は同じ（④の適用税率は不要）、⑤消費税額等**又は**適用税率、宛名は不要 | 消費税法 第57条の4第2項／概要 P4 |
| 簡易インボイスを出せる事業 | 小売業・飲食店業・写真業・旅行業、タクシー業、駐車場業（不特定多数向け）、これらに準ずる不特定多数向けの事業 | 消費税法施行令 第70条の11 |
| 返還インボイスの記載事項 | ①発行者の名称と登録番号 ②返還等を行う年月日と、基となった取引の年月日 ③取引の内容 ④税率ごとの返還等の金額 ⑤消費税額等又は適用税率 | 消費税法 第57条の4第3項／概要 P8 |
| 返還インボイスの交付義務の免除 | 返還等の税込価額が1万円未満 | 消費税法施行令 第70条の9第3項第2号／概要 P8 |
| 複数の書類・取引先コード表 | 関連が明らかな複数の書類で記載事項を満たせばよい。登録番号を取引先コード表などで共有していれば記載があるものとして扱う | 概要 P6 |
| 消費税額等の計算と端数処理 | 税率ごとの合計 ×10/100・8/100（税抜）又は ×10/110・8/108（税込）。1円未満は、一の適格請求書につき税率ごとに1回だけ処理（切捨て・切上げ・四捨五入は任意）。明細ごとに端数処理して合計するのは不可 | 消費税法施行令 第70条の10／概要 P7 |
| 登録番号の形 | 法人番号のある課税事業者は「T」＋法人番号（13桁）。それ以外（個人事業者・人格のない社団等）は「T」＋13桁（マイナンバーは使わず、法人番号と重ならない） | 国税庁 公表サイト「登録番号とは」 |
| 法人番号の検査用数字 | 9 −（Σ Pn×Qn を9で割った余り）。Pn は基礎番号12桁の下から n 桁目、Qn は n が奇数なら1・偶数なら2 | 国税庁「法人番号の構成」（法人番号の指定等に関する省令 第2条） |
| 個人事業者の番号の検査用数字 | 公表された決まりが見つからない → 法人番号の式に合わなくても「要確認」にとどめ、公表サイトで確かめる | （公式の記載なし） |
| 公表情報の照会 | Web-API: `/1/num`（番号）・`/1/valid`（番号と基準日）、1回10件まで。ID は使う人ごと（第三者に渡さない）。結果には第6条の文言を出す | Web-API 第二編（Ver.1.0）／Web-API 利用規約 第6条・第9条 |
| 電帳法のファイル名 | 「取引年月日」「取引金額」「取引先」を入れ、統一した順序で付ける（例 `20210131_㈱霞商店_110000`）。金額は税抜・税込のどちらでもよいが一貫させる。1か月分をまとめた書類は発行日と合計でもよい | 国税庁「電子帳簿保存法一問一答【電子取引関係】」（令和8年7月）問50・問57・問55 |
| 検索要件が要らない場合 | 基準期間の売上高5,000万円以下で、税務職員のダウンロードの求めに応じられるとき等 | 同 問51 |
